# 日本語トレーニング / 日語學習 App

給學生使用的日語練習網頁,涵蓋:

- 五十音(清音／濁音／半濁音)flashcard,含語音朗讀
- N5 單字(假名／漢字／羅馬拼音／中文意思／例句)
- N5 文法點(解說＋例句)
- 日常會話句型(依情境分類:打招呼、自我介紹、購物、餐廳、問路等)

已學狀態存在瀏覽器 localStorage。如需跨裝置同步,可在 `index.html` 中將 `SYNC_URL`
換成自己的 Google Apps Script `/exec` 網址。

## 使用方式

直接開啟 `index.html`,或透過 GitHub Pages 部署後用網址存取。
